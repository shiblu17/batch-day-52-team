# Sponsors & Partners 🤝

ব্যাচ ইভেন্টের স্পন্সর, পার্টনার এবং আমাদের আউটরিচ ট্র্যাকিং।

## 📂 কী কী ট্র্যাক করবেন
| আইটেম | কী থাকবে |
|-------|----------|
| স্পন্সর লিস্ট | কোম্পানি/ব্র্যান্ড নাম, কন্টাক্ট, প্যাকেজ |
| প্রপোজাল | কাকে প্রপোজাল পাঠানো হয়েছে, স্ট্যাটাস |
| মিটিং | কার সাথে মিটিং বসেছে, কী আলোচনা |
| পাইপলাইন | লিড → কন্টাক্টেড → নেগোশিয়েটিং → কনফার্মড → সাইনড |

## 🔹 Sponsor টেমপ্লেট
```
## [কোম্পানি/ব্র্যান্ড নাম]
- কন্টাক্ট: [নাম, ফোন, ইমেইল]
- প্যাকেজ: [প্যাকেজের ধরন]
- স্ট্যাটাস: Lead / Contacted / Negotiating / Confirmed / Signed / Lost
- নোট: 
```

## 🔹 Proposal টেমপ্লেট
```
## [কোম্পানি] — প্রপোজাল
- তারিখ: YYYY-MM-DD
- পাঠানো হয়েছে: Yes / No
- রেস্পন্স: Pending / Interested / Rejected
- নোট: 
```

## 🔹 Meeting টেমপ্লেট
```
## [YYYY-MM-DD] — [কোম্পানি] মিটিং
- কাকে: 
- আলোচনা: 
- নেক্সট স্টেপ: 
```

## 📊 পাইপলাইন (স্টেজ)
`Lead → Contacted → Negotiating → Confirmed → Signed`
